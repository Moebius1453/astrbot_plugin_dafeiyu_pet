# astrbot_plugin_dafeiyu_pet

把 QQ 智能体接到 Windows 桌面桌宠上。轻量化桌宠，功能简单：桌宠是身体，AstrBot 是大脑。聊天时同步冒气泡，戳它、拖它、喂它，也能让模型知道。

基于 [1190fasheqi/dafeiyu-pet](https://github.com/1190fasheqi/dafeiyu-pet) 改造。

## 更新日志

### v1.1.1 · 2026.10.15

新增：

- 气泡配置：支持开启或关闭气泡，设置每段字数上限，默认 40 字，也可以改成 15 字等数值。关闭气泡不影响 QQ 回复和动作。
- 主动回应开关：默认关闭。开启后，戳它、拖它、喂它，或者安静一段时间，它可能主动冒一句气泡。
- 函数工具控制：通过 `pet_action` 执行跳跃、摇晃、伸懒腰、模式切换和八方向移动，不再依赖回复里的动作标签。
- 位置感知：通过 `pet_state` 查询桌宠位置、所在屏幕、屏幕边界、当前模式和移动目标，让模型知道它在哪、有没有走到。

修复与优化：

- 桌宠控制和回复同步仅处理主人 QQ 私聊，避免其他会话影响桌宠。
- 取消普通回复默认切换为“待着”的行为，不再聊一句就打断散步。
- 修正移动目标的坐标偏移，方向移动到达后停留，并补充小屏幕和负坐标边界处理。
- 修复单击松开后仍暂停移动、气泡第二行丢字，以及相同文本无法再次显示的问题。
- 优化回复同步顺序，减少输出分段插件对气泡正文的影响；`/say` 自动启动桌宠后会等待接口就绪再发送。
- 动作由界面线程处理，天气查询改为后台执行，减少窗口卡顿与跨线程操作问题。
- 主动回应加入冷却和并发限制；生成期间有新的主人对话时，不再显示过时回应。
- 桌宠设置与错误日志独立保存，更新插件时便于保留配置。

## 特性

一只住在 Windows 桌面上的大肥鱼，大脑是 AstrBot：

- QQ 对话同步：主人私聊时，机器人的文字回复同步出现在桌宠气泡里。
- 互动感知：点击、拖动、喂食会作为近期身体事件供模型读取。
- 说话控制：在 QQ 里说“跳一下”“伸个懒腰”，由模型调用工具控制桌宠。
- 八方向移动：向左、向右、向上、向下和四个角，走到后停留。
- 跟随与散步：可以跟着鼠标走，也可以自由散步或原地待着。
- 位置查询：模型可以查询当前坐标、屏幕范围、移动模式和目标。这里的屏幕感知只涉及坐标与边界，不读取屏幕内容。
- 可选主动回应：使用主人会话的模型与人格，偶尔主动说一句，只显示在桌宠气泡里。
- 进程托管：通过 QQ 命令启动、停止桌宠；AstrBot 退出后，桌宠会在心跳检测失联后退出。
- 天气与系统提醒：右键查看天气，保留 CPU、内存等系统状态提醒；显卡温度检测取决于可用的硬件与依赖。

## 快速开始

### 使用前提

- AstrBot 运行在有图形桌面的 Windows 环境中，桌宠显示在运行 AstrBot 的那台电脑上。
- 已接入 `aiocqhttp` QQ 平台，并配置可正常聊天的模型。
- 自然语言动作控制需要模型支持函数调用。

### 安装与启动

1. 从 AstrBot 插件市场安装本插件，或将仓库放入 AstrBot 的 `data/plugins/astrbot_plugin_dafeiyu_pet/` 目录。
2. 确认 AstrBot 使用的 Python 环境已安装 `requirements.txt` 中的依赖：`httpx`、`PySide6`、`psutil`。手动补装时，在该 Python 环境中、AstrBot 根目录下执行：

   ```powershell
   python -m pip install -r ./data/plugins/astrbot_plugin_dafeiyu_pet/requirements.txt
   ```

3. 在插件配置中填写 `master_qq`，保存并重载插件。
4. 使用该 QQ 私聊机器人，发送 `/pet start`。
5. 桌宠出现后，就可以聊天、让它做动作，或者直接戳它、喂它。

若人格设置了工具白名单，请允许 `pet_action` 和 `pet_state`。

## 配置

在 AstrBot 插件面板中设置：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `master_qq` | 留空 | 主人 QQ 号，仅该 QQ 私聊可控制桌宠和同步回复。建议明确填写；留空时绑定本次运行的首个私聊发送者。 |
| `bubble_enabled` | `true` | 是否显示桌宠文字气泡，不影响 QQ 回复和动作。 |
| `bubble_max_chars` | `40` | 气泡每段字数上限，范围 1 到 200。长文本最多分 3 段，每段仍受两行显示宽度限制，过长会省略。 |
| `proactive_enabled` | `false` | 是否允许互动和安静时段触发主动气泡回应。 |

修改配置时，先 `/pet stop`，在面板保存并重载插件，再 `/pet start`，使桌宠使用新设置。

### 主动回应

想让它偶尔自己说话，可以同时开启 `proactive_enabled` 和 `bubble_enabled`，再由主人私聊一句话建立会话关联。之后点击、拖动、喂食或安静一段时间，都可能触发回应。

主动回应有概率和 30 秒冷却，不保证每次互动都说话。它使用主人会话选择的模型和人格，会产生额外模型调用费用；不加载聊天历史或其他插件的记忆，不调用动作工具、不发送 QQ，也不写入聊天历史。关闭气泡时不会触发主动生成。

### 桌宠设置与天气

右键桌宠或托盘图标，可以调整移动模式、大小、置顶、鼠标穿透等选项。开启鼠标穿透后，可从托盘菜单解除。

桌宠设置保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_dafeiyu_pet/config.json`，天气使用其中的 `city` 字段。

旧版配置文件不会自动迁移，新目录首次使用默认设置；需要保留旧设置时，请先备份，再将需要的设置填入新配置。

## 玩法示例

| 输入或操作 | 桌宠反应 |
| --- | --- |
| 跟着我的鼠标 | 切换到跟随模式 |
| 去右上角 / 向右 / 往上 | 向当前屏幕对应的角或边缘移动，到达后停留 |
| 跳一下 / 伸个懒腰 / 摇一摇 | 做对应动作 |
| 待着 / 别动 / 散步 | 切换移动模式 |
| 你现在在哪？走到了吗？ | 模型可调用工具查询位置和移动状态 |
| 点击 / 拖动 / 喂食 | 上报互动事件；开启主动回应后，可能冒一句气泡 |
| 右键菜单“查看天气” | 显示所设城市的天气 |
| 普通私聊 | 文字回复同步到桌宠气泡 |

动作是否执行取决于模型的工具调用。普通聊天不需要附加动作标签；“待着”只停止移动，仍会保留呼吸和偶尔的小动作。

## 命令一览

以下命令均由主人 QQ 私聊发送：

| 命令 | 作用 |
| --- | --- |
| `/pet start` | 启动桌宠 |
| `/pet stop` | 停止插件托管的桌宠进程 |
| `/pet status` | 查看桌宠接口是否在运行 |
| `/say <文本>` | 在气泡中显示指定文字；桌宠未启动时会尝试启动。气泡关闭时不显示文字。 |

## 常见问题

### 桌宠没有出现

确认 AstrBot 运行在 Windows 图形桌面环境中，插件已启用，依赖安装在 AstrBot 实际使用的 Python 环境里。发送 `/pet status` 查看状态，未运行时发送 `/pet start`；启动失败请查看 AstrBot 日志。

桌宠显示在运行 AstrBot 的电脑上，不会显示在发 QQ 消息的手机或另一台电脑上。

### 有 QQ 回复，但没有气泡

先确认 `bubble_enabled` 已开启，修改配置后已重载插件并重新启动桌宠，再用 `/say 你好` 单独测试。气泡每段显示约 2.8 秒。

如果仍看不到，请保留 `/say` 返回结果和对应时段的 AstrBot 日志，反馈时一并提供。

### 能聊天，但不执行动作

检查模型是否支持函数调用，以及人格是否允许 `pet_action`、`pet_state`。动作由模型调用工具执行，不再依赖关键词匹配或回复中的动作标签。

### 互动了，它为什么不主动说话？

主动回应默认关闭。开启后还需要开启气泡，并由主人先私聊一次。互动有概率和冷却，不是每次都会回；调用失败时，AstrBot 日志会出现“桌宠主动回应失败”。

不开主动回应也能感知互动：近期事件会在接下来的主人对话中提供给模型，保留时间为 5 分钟。

### 为什么主动说话没有发到 QQ，也不记得之前聊过什么？

主动回应是独立的桌宠气泡生成，只使用所选模型与人格，不读取聊天历史。普通 QQ 聊天仍由 AstrBot 原有对话流程处理。

### 桌宠自己退出了

AstrBot 关闭后，桌宠会在心跳检测连续失联约 30 秒后退出，这是设计行为。
